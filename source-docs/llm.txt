[ LLM ] --> เป็น Model ที่นำข้อมูลมาคำนวณในรูปแบบ "ความน่าจะเป็น" แล้วนำมาเทียบกับ "ความสัมพันธ์" ที่มี แล้ว Outcome ออกมาเป็นคำตอบในรูปแบบของ "Prediction"

[ Generative AI ] :
Generative : การที่มนุษย์เรา [ใช้/สั่ง] ให้สิ่งๆนึงมันสร้าง Outcome ขึ้นมาโดยที่ไม่ใช่ฝีมือเรา

[ ลักษณะการทำงานของ Neural Network ] --> มันจะแปลงข้อมูลแต่ละขั้นเป็น "เลขความน่าจะเป็น" แล้วจับทั้งหมดมา x กันแล้ว predict ว่าผลลัพธ์ใกล้เคียงกับ Outcome รูปแบบไหน

[Neural Network ที่ใช้ใน LLM => Transformer] -> เป็นการนำข้อมูลมาเทียบความสัมพันธ์แล้วสร้างเป็นข้อมูลชุดใหม่ออกมา

[องค์ประกอบ] : 
Encoder => ตัวแปลงข้อมูลจาก text -> vector
Decoder => ตัวแปลงข้อมูลจาก vector กลับมาเป็น text

[ Transformer Process ]

  Input                   --> [ แปลง Text ซอยออกมาเป็น Token ด้วยวิธี "Tokenized" ] --> [Embeddings] --Encoder--> [Vector] x [Weight Vector (dict)] --Decoder--> Max(dict) --> เลข 0.5 ซึ่งมีค่าเป็น แมว --พ่น--> Output
  [ Q: สัตว์อะไรน่ารักที่สุด ? ]                                                                                                           |                                                                   [ A : แมว ]
                                                                                                                                    |
                                                                                                                                    |
                                                                                                                                    v
                                                                                                                    Attention => ตัวคำนวณความสัมพันธ์ของข้อมูล

[ LLM คืออะไรแล้วแท้จริง? ]
- LLM = Model ที่ใช้ Neural Network ประเภท Transformer ในการคำนวณ โดยใช้ Parameter ที่มี "ขนาดใหญ่" (#Feature ที่มากมายมหาศาล) มาคำนวณนั่นเอง แล้ว Outcome ออกมาในรูปแบบ Prediction

[ ศัพท์จำเป็น ]

[ In-Context Learning ]
- คือการทำ "Data Preparation" ให้กับ LLM ให้ดีและมากที่สุด เพื่อให้เราได้ Outcome ที่ดีที่สุดเช่นกัน

[ Pretrain Model ]
- คือ Model ที่ผ่านการ Trained มาแล้วเรียบร้อย
- แต่ข้อมูลที่ผ่านการ Trained พวกนี้มาจากการดำเนินการผ่าน "ความสัมพันธ์ภายในข้อมูล" เท่านั้น หรือที่เรียกว่า "Unsupervised Learning" --> Model ตัวนี้จะไม่สามารถใช้กับงานที่ Specialization ได้ (สรุปง่ายๆ Pretrained คือ เด็กเนิร์ดที่รู้มากแต่ไม่ได้ specialist ในด้านใดๆ)

[ Supervised Learning & Instruct Model]
- Supervised Learning => Model ที่ผ่านการ "Fine-Tuning" เพื่อให้ Model สามารถทำงานเฉพาะทาง (Specialist) ได้อย่างมั่นใจและแม่นยำ
- ซึ่ง Model กลุ่มนี้จะเรียกว่า "Instruct Model"

[ Reinforcement Learning ]
- เป็นการที่มนุษย์เราสอน Model ที่ on production แล้วว่าแบบนี้ไม่ถูกนะ ต้องตอบแบบนี้ๆ (ซึ่งสิ่งที่เราบอกมันนี้ Model จะนับ Feedback พวกนี้เป็น "Reward" สำหรับ Model มัน) โดยผ่านการ input บน Frontend ของ Model เช่น Chat , API Response รูปแบบต่างๆ เพื่อให้ Model เฉียบคมมากขึ้น
